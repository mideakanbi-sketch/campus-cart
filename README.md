\# CampusCart



\## Overview



CampusCart is a command-line platform that helps campus vendors manage menus and receive student orders.



\## Problem Statement



Students need an easy way to find available campus vendors and products. Vendors need a simple way to reach students.



\## Target Users



\- Students

\- Campus vendors

\- Administrators



\## Core Features



\- View vendors

\- Browse products

\- Add products to a cart

\- Place an order

\- View order details
