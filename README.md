\# CampusCart



\## Overview



CampusCart is a command-line platform that connects students with campus vendors to compare products, manage menus, and place affordable orders.



\## Problem Statement



Students need an easy way to find available campus vendors and products. Vendors need a simple way to reach students.



\## Target Users



\- Students

\- Campus vendors

\- Administrators



\## Core Features



\- View vendors

\- Browse products

\- Add products to a cart

\- Place an order

\- View order details



## User Personas

### Student

A student needs a fast way to find affordable food and products between classes.

### Vendor

A vendor needs a simple way to list products and receive orders from students.
